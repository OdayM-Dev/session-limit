# Changelog

## 1.0.1 — 2026-10-16

- The author's GitHub account is now OdayM-Dev. The links, the license and the install commands follow it.

## 1.0.0 — 2026-10-16

- **Says what's missing.** If Python, numpy or pillow is missing, a message in Claude now says what to install, in the ring's language. Before, the ring just didn't appear. Opening the ring by hand without them shows a warning box.
- **Tests run anywhere.** They no longer depend on where the plugin sits on disk.
- README with images, and an MIT license.

## 0.9.0

- First public version: the ring, its hover card and forecast, the siren and chime, the tray icon, Codex support, Arabic and English.
